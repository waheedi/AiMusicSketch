# First public release

A native macOS music sketchpad for recording, arranging, synthesizing, mixing and optional local AI generation.

## Included

- Multitrack editing without a fixed track-count limit, audio import, clip copy/loop/trim/resize, undo/redo and stereo WAV export.
- A pinned beat/time ruler, follow-playhead, **⌘+ / ⌘−** zoom and **R** to start/stop recording.
- Microphone/audio-input recording, computer-keyboard and MIDI playing, and editable notes in new supported native-instrument takes.
- Signature and Aurora kits, Sketch Synth, Kick Lab, Oud Lab, Violin Lab and Shaker Lab.
- Audio Unit instrument hosting, including Surge XT's editor and preset browser, with computer-key playing while its window is focused.
- Per-track effects, filters and timeline automation.
- Optional local MusicGen audio generation and Ollama note generation, with per-track audio references and extended generation ranges.

## Download and install

Download **AI-Music-Sketchpad-0.11.0-macOS-universal.zip** below. Requires **macOS 15+**; contains Apple Silicon and Intel binaries. Intel is cross-compiled, not hardware-tested. Extract it, move the app to Applications, and see the included `INSTALL.md`. `SHA256SUMS.txt` verifies the ZIP.

**Signing:** this release is ad-hoc signed, not Developer ID signed or notarized. macOS may require a one-time **Open Anyway** approval in Privacy & Security. See [Apple's instructions](https://support.apple.com/en-us/102445); do not disable Gatekeeper globally.

## Optional dependencies and limitations

Surge XT, Apple sound libraries, Ollama, Python dependencies and AI model weights are **not bundled**. Native mixing and original synths work without AI setup. The archive includes the optional MusicGen setup scripts; Apple Silicon is recommended for the app and required by the supported AI setup. MusicGen Small weights are **CC BY-NC 4.0 (noncommercial)**, separate from the app's Apache-2.0 license.

Third-party AU takes are audio-only for note editing. Plug-ins run in-process. Projects reference external audio files and plug-ins, so transferring only the project JSON is not enough. Large sessions remain limited by available CPU and memory.
